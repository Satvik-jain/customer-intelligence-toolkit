# Pricing and WTP method guide

## Monetization structure

| Structure | Consider when | Check |
|---|---|---|
| Subscription | Ongoing access or value | Churn, usage variation, renewal value |
| Usage-based | Value or cost scales with consumption | Bill predictability, metering, customer control |
| Transaction fee | Revenue is tied to a completed exchange | Platform-side incentives and total transaction cost |
| Tiered/versioned | Needs or value differ across customers | Tier boundaries map to meaningful value |
| Bundled | Components work together or simplify choice | Avoid forcing low-value features |
| Hybrid | Multiple value or usage patterns justify it | Added complexity and fairness |

## WTP evidence

- Direct questions and surveys measure stated preference.
- Conjoint/discrete choice measures trade-offs under a specified choice design.
- Incentive-compatible methods can introduce real payment consequences in a designed study.
- Transactions and field price tests observe behavior in context but need appropriate analysis.
- Synthetic panels provide exploratory scenarios only; they do not measure actual WTP.

WTP is relative to product, alternatives, context, segment, and method. Do not apply a universal correction factor. Choose a method for the decision, state assumptions, and validate consequential prices with observed behavior where feasible.
